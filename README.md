# HostelHub PMS

Professional Hostel Property Management System — Web + Android + Public Site + Supabase.

## Stack
- **Web:** Next.js 14 (App Router), TypeScript, Tailwind, shadcn/ui, TanStack Query, Recharts
- **Mobile:** Expo + React Native + Expo Router
- **Backend:** Supabase (Postgres + Auth + Storage + Edge Functions + pg_cron)
- **Exports:** SheetJS (Excel), jsPDF + AutoTable (PDF)
- **Push:** Firebase Cloud Messaging via expo-notifications
